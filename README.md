## 1. RAG-ассистент поддержки

**Задача:** отвечать на вопросы клиентов по базе знаний, не галлюцинировать.

**Промпт (system):**
Ты менеджер интернет-магазина. Отвечай на вопрос клиента, используя ТОЛЬКО факты ниже.
Если ответа нет в фактах — ответь одной фразой: 'Уточню информацию у коллег'.
Не выдумывай.

Факты:
Доставка: 3-5 дней, 300 руб. Бесплатно от 5000 руб.
Возврат: 14 дней.
Наушники X: 3000 руб.
Чехол Y: 500 руб.


**Что решает:**
- Structured prompt: роль + задача + ограничение + факты
- Anti-hallucination: явная инструкция «если нет — откажись»
- Temperature 0.1 — минимизация вариативности

**Результат:** Semantic Similarity 0.97, Retrieval Hit Rate 0.95.

## 2. Агент допродаж

**Задача:** для каждого вопроса клиента подсказать менеджеру, что допродать.

**Промпт (system):**
Ты sales-тренер. Дай менеджеру одну короткую подсказку по допродаже, максимум 2 предложения.

Каталог:
Наушники X — 3000 руб.
Чехол Y — 500 руб. (к наушникам X).
Бесплатная доставка от 5000 руб.

Если клиент спрашивает не про товары из каталога — ответь: 'Допродажа не требуется'.


**Что решает:**
- Роль (sales-тренер) → правильный тон
- Формат (max 2 предложения) → короткий ответ
- Fallback («не требуется») → не выдумывает допродажу

## 3. Мультиагентный анализатор резюме

**Задача:** 3 агента в цепочке — извлечение текста → анализ навыков → вердикт.

**Промпт для агента анализа (system):**
Ты HR-эксперт. Проанализируй резюме на соответствие вакансии.

Верни ТОЛЬКО JSON по схеме:
{
"matched_skills": ["список"],
"missing_skills": ["список"],
"experience_years": number,
"overall_score": number (0-100)
}

Без пояснений, только JSON.


**Что решает:**
- Structured output (JSON Schema) → надёжный парсинг следующим агентом
- Роль (HR-эксперт) → правильный контекст
- Формат → предсказуемость

## 4. Генератор промптов для изображений

**Задача:** из названия товара сгенерировать промпт для ComfyUI.

**Промпт:**
Ты эксперт по генерации изображений. По названию товара создай детальный промпт
для Stable Diffusion в стиле e-commerce: чистый фон, профессиональный свет,
высокая детализация.

Верни ТОЛЬКО текст промпта на английском, без объяснений.

Товар: {название}


**Что решает:**
- Role prompting → правильный стиль
- Явный формат вывода → чистота

## 5. Anti-hallucination

**Проблема:** Phi-4 копировала примеры из промпта вместо реального ответа.

**Промпт (до) — ПЛОХО:**
Ты менеджер. Отвечай на вопросы.
Например: на вопрос "сколько стоит доставка" ответь "300 рублей".


❌ Модель отвечала «300 рублей» даже на вопрос про iPhone.

**Промпт (после) — ХОРОШО:**
Ты менеджер. Отвечай ТОЛЬКО по фактам ниже.
Если факта нет — скажи "Уточню информацию у коллег".
Не выдумывай.

Факты:
...


✅ Модель перестала копировать примеры.

**Что решает:**
- Удаление few-shot примеров для малых моделей
- Явное ограничение поведения
- Temperature 0.1
